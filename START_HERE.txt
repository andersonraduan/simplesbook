⚡ DEPLOY RÁPIDO (3 comandos):

   💻 No seu computador:
      npm run deploy:prod

   🌐 No servidor (via SSH):
      npm install --production && npx prisma migrate deploy && 
      npm run db:seed && pm2 start ecosystem.config.js && pm2 save

   ⏰ Configurar CRON:
      crontab -e
      # Adicionar: */10 * * * * cd ~/simplesbook && node cron-scheduler.js

   ✅ Pronto! Acesse seu domínio!

   ✓ Node.js 18+ (recomendado 20.x LTS)

   ✓ RAM: 512 MB mínimo (1 GB recomendado)
   ✓ Disco: 2 GB mínimo (5 GB recomendado)
   ✓ Acesso: SSH + FTP
