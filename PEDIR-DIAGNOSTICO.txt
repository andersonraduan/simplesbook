==========================================
SCRIPT DE DIAGNÓSTICO
==========================================

Para identificar o problema do "Internal Server Error",
execute este script no servidor e me envie a saída completa:

cd ~/calendario.clinicalasante.pt
chmod +x diagnostico-completo.sh
./diagnostico-completo.sh

==========================================
OU execute estes comandos manualmente:
==========================================

cd ~/calendario.clinicalasante.pt && \
export PATH="$HOME/nodevenv/calendario.clinicalasante.pt/24/bin:$PATH" && \
echo "=== 1. Status PM2 ===" && \
pm2 status && \
echo "" && \
echo "=== 2. Porta 3000 ===" && \
netstat -tuln 2>/dev/null | grep 3000 || lsof -i :3000 2>/dev/null || echo "Porta 3000 não está escutando" && \
echo "" && \
echo "=== 3. Teste de conexão ===" && \
curl -I http://localhost:3000 2>&1 | head -5 && \
echo "" && \
echo "=== 4. Arquivos essenciais ===" && \
ls -la .env ecosystem.config.js .next/server/ 2>&1 | head -10 && \
echo "" && \
echo "=== 5. LOGS DE ERRO (últimas 50 linhas) ===" && \
pm2 logs simplesbook --err --lines 50 --nostream 2>&1 | tail -50 && \
echo "" && \
echo "=== 6. Variáveis de ambiente ===" && \
grep -E "NEXTAUTH_SECRET|DATABASE_URL|NODE_ENV" .env 2>&1 || echo ".env não existe ou não tem as variáveis"
